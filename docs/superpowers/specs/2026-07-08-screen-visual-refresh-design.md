# TokenHub 大屏视觉优化规格

## 目标

把 `/screen` 做成适合局域网展示的实时运营大屏：信息密度高、首屏可读、无外链依赖、加载速度快。

## 约束

- 不使用 CDN、远程字体、远程图片、外部脚本或外链样式。
- 保持现有 `/screen-api/dashboard/*` 接口调用，不新增多媒体面板请求。
- 前端动态内容继续使用 DOM API 渲染，不使用 `innerHTML`。
- 保留 `/screen/{share_code}` 自动识别分享码的登录方式。

## 设计方向

- 顶部使用指挥中心式标题区，包含当前时间、刷新状态和退出按钮。
- 首屏使用核心指标卡片，突出今日请求、Token、成功失败和平均延迟。
- 趋势、排行、安全、性能改为图形化信息块，减少表格堆叠。
- 使用本地 CSS 背景网格、线性高光和半透明面板营造大屏感。
- 移动端保持单列，保证文本不溢出。
