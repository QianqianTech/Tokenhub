# API 密钥操作图标设计

## 目标

将后台“API 密钥”列表操作列中因字符编码错误显示的编辑、删除文字替换为清晰的图标按钮。

## 范围

- 仅修改 `public/admin/assets/js/table.js` 中 API 密钥列表每行的编辑与删除操作。
- 使用项目原生 DOM API 创建内联 SVG：铅笔表示编辑，垃圾桶表示删除。
- 沿用已有 `.api-key-icon-button` 和危险操作样式，不新增图标库或静态资源。

## 交互与无障碍

- 保持现有点击行为：编辑打开编辑弹窗；删除仍先弹出确认框，确认后调用原有删除接口并刷新列表。
- 保留 `title` 与 `ariaLabel`，使图标可被鼠标悬停和辅助技术识别。
- SVG 设为 `aria-hidden`，避免与按钮标签重复朗读。

## 验证

- 先增加前端契约测试，断言 API 密钥操作区不再包含乱码字符，且创建编辑、删除 SVG 图标的辅助逻辑存在。
- 运行该测试及关联 API 密钥前端测试；通过 Docker PHP 运行，因为本机环境未假设安装 PHP。
