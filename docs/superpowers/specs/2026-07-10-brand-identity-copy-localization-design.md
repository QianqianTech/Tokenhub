# 标题与标识文案中文化设计

## 目标

将“标题与标识”设置的用户可见说明改为中文，减少中英文混杂；接口使用的配置键保持不变。

## 范围

- 修改 `brand_identity` 的系统设置说明，使其表达为“管理后台和运营大屏的标题、Logo 与浏览器图标设置”。
- 保留 `brand_identity`、`product_name`、`admin_title`、`screen_title`、`logo_url`、`favicon_url` 等配置键，避免改变保存接口和已有数据。
- 不修改管理后台与运营大屏实际标题值、品牌读取逻辑、后端接口、数据库、环境配置或部署配置。

## 方案比较

- 方案 A（采用）：只替换后端提供给设置表单的说明文字。改动最小，能直接解决截图中的英文说明。
- 方案 B：同时将配置键显示为中文。会模糊接口键与展示标签的边界，也可能影响管理员定位配置，故不采用。
- 方案 C：全面清理所有系统设置中的英文。覆盖面过大，超出本次截图所指的问题，故不采用。

## 实现与验证

在 `SystemSettingsService` 中替换 `brand_identity` 的说明文案，并在既有系统设置前端契约测试中断言该中文说明存在、旧英文说明不存在。先运行测试确认它因文案仍为英文而失败；完成最小修改后，在 Docker PHP 环境中重跑该聚焦测试。

## 非目标

- 不翻译技术配置键或 API 字段。
- 不更改用户已保存的品牌名称、管理后台标题或运营大屏标题。
