# 07 内容留存、会话存档和导出任务清单

## 目标

实现用户输入、模型输出、生成内容、会话存档、CSV 导出、导出审计和保留天数配置。

## 数据表

- `usage_contents`
- `export_tasks`
- `system_settings`
- `audit_logs`

## 开发任务

- [x] 创建 `usage_contents` 表，关联 `usage_records`，保存输入内容、输出内容、脱敏内容、摘要、过期时间。
- [x] 支持系统、部门、用户、API Key 级内容留存策略。
- [x] 支持只保存摘要、保存脱敏内容、保存原文三种模式。
- [x] 默认保存天数可配置，支持最大保存天数限制。
- [x] 到期清理正文，但保留调用明细和清理状态。
- [x] 查看用户生成内容必须服务端校验权限并写审计日志。
- [x] 普通用户只能查看自己的内容。
- [x] 管理员只能查看授权部门及子部门内容。
- [x] 超级管理员查看全局内容也必须写审计。
- [x] 实现会话存档查询，按用户、部门、Key、模型、时间范围组合调用。
- [x] 实现会话存档 CSV 导出任务。
- [x] 实现用量明细 CSV 导出任务。
- [x] 实现日志 CSV 导出任务。
- [x] 导出任务异步执行，状态包含排队、处理中、成功、失败、已过期。
- [x] 导出文件使用短期下载链接。
- [x] 导出文件到期后自动删除。

## 测试任务

- [x] 启用原文留存后，授权用户可以查看输入和输出内容。
- [x] 关闭原文留存后，只保存摘要或脱敏内容。
- [x] 内容到期清理后，明细仍存在，正文不可查看。
- [x] 普通用户不能查看其他用户生成内容。
- [x] 管理员不能越权查看非授权部门内容。
- [x] 会话存档导出只包含授权范围数据。
- [x] 原文导出需要单独权限并写审计日志。
- [x] 导出文件过期后下载失败。
- [x] 导出 CSV 不包含 API Key 明文、厂商密钥、Authorization、Cookie。

## 验收标准

- 内容留存天数可配置。
- 生成内容可按权限查看、清理、导出。
- 所有查看和导出行为可审计。
- CSV 导出适合日志、会话存档和明细归档。
