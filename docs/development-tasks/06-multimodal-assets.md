# 06 多模态和媒体资产任务清单

## 目标

支持文本、视觉理解、ASR、TTS、文生图、文生视频等能力，并统一多模态任务、媒体资产和短期下载链接。

## 数据表

- `multimodal_tasks`
- `media_assets`
- `usage_records`

## 开发任务

- [x] 定义多模态能力枚举：文本、视觉、Embedding、ASR、TTS、文生图、文生视频。
- [x] 创建 `multimodal_tasks` 表，记录任务类型、状态、厂商任务 ID、错误、耗时、用户、部门、模型。
- [x] 创建 `media_assets` 表，记录文件类型、路径、大小、时长、分辨率、过期时间、访问权限。
- [x] 实现 ASR 请求适配，记录音频秒数、识别文本、失败原因。
- [x] 实现 TTS 请求适配，记录输入字符数、输出音频秒数、媒体资产。
- [x] 实现视觉理解请求适配，记录图片数量、输入 Token、输出 Token。
- [x] 实现文生图任务，记录图片数量、分辨率、资产路径。
- [x] 实现文生视频任务，记录视频秒数、分辨率、任务状态、资产路径。
- [x] 长任务使用异步任务，返回 `task_id`。
- [x] 实现 `GET /v1/tasks/{id}` 查询任务状态。
- [x] 实现 `GET /v1/assets/{id}/download-url` 获取短期下载链接。
- [x] 媒体资产下载必须校验用户、部门、Key 或大屏分享范围。
- [x] 媒体资产到期清理只删除文件，不删除业务明细。

## 测试任务

- [x] ASR 能记录音频时长、识别结果、任务状态。
- [x] TTS 能记录输入字符数、输出音频资产。
- [x] 文生图能记录生成图片数量、分辨率、下载权限。
- [x] 文生视频能记录任务状态、视频秒数、下载权限。
- [x] 无权限用户不能访问其他用户媒体资产。
- [x] 短期下载链接过期后无法继续下载。
- [x] 媒体资产路径不暴露对象存储永久地址。
- [x] 多模态调用能进入用量统计和大屏模态分析。

## 验收标准

- 多模态能力统一通过 OpenAI/Anthropic 兼容接口对外提供。
- 厂商原生差异被内部适配器屏蔽。
- 媒体资产访问受权限、有效期和审计控制。
