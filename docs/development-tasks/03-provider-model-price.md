# 03 厂商、模型和价格配置任务清单

## 目标

实现厂商接入、模型配置、能力声明、可选价格配置和成本快照基础。

## 数据表

- `providers`
- `models`
- `model_prices`
- `audit_logs`

## 开发任务

- [x] 创建 `providers` 表，保存厂商名称、协议类型、基础地址、加密密钥、状态、超时、重试、默认 Header。
- [x] 厂商密钥使用服务端加密存储，禁止明文入库。
- [x] 支持厂商类型：OpenAI 格式、Anthropic 格式、厂商原生适配器。
- [x] 创建 `models` 表，保存模型名称、厂商、能力类型、上下文长度、是否启用、路由优先级。
- [x] 能力类型支持：文本、视觉理解、Embedding、ASR、TTS、文生图、文生视频。
- [x] 创建 `model_prices` 表，保存输入价格、输出价格、音频秒价格、TTS 字符价格、图片价格、视频秒价格、币种、生效时间。
- [x] 价格配置允许为空；为空时只统计用量，不计算成本。
- [x] 实现厂商 CRUD 和启停接口。
- [x] 实现模型 CRUD、启停和能力配置接口。
- [x] 实现价格新增、编辑、按生效时间查询。
- [x] 调用明细写入时保存价格快照，历史成本不因价格调整重算。
- [x] Admin 页面提供厂商、模型、价格配置入口。
- [x] 厂商密钥创建和编辑只显示一次或显示脱敏摘要。
- [x] 所有厂商、模型、价格变更写入审计日志。

## 测试任务

- [x] 未配置价格时，调用统计仍可正常写入，成本字段为空。
- [x] 配置价格后，调用明细能按命中的价格快照计算成本。
- [x] 修改价格后，历史调用成本不变化，新调用使用新价格。
- [x] 禁用厂商后，路由不能选择该厂商。
- [x] 禁用模型后，API Key 调用该模型返回 `MODEL_FORBIDDEN` 或模型不可用错误。
- [x] 厂商密钥不出现在 API 响应、日志、审计详情和前端状态中。

## 验收标准

- 可以配置至少一个 OpenAI 格式厂商和一个 Anthropic 格式厂商。
- 可以配置腾讯云等厂商原生适配器的基础信息。
- 价格配置是可选能力，不影响内部免费或对内场景。
- 所有价格和密钥变更可审计。
