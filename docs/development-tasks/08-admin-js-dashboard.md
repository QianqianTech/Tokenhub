# 08 Admin 后台和智慧大屏任务清单

## 目标

实现原生 JS/TypeScript Admin 后台、统一 API 封装、智慧大屏、排行、趋势、下钻和系统设置页面。

## 前端约束

- Caddy 托管静态 HTML、JS、CSS。
- 前端只调用同域 `/admin-api/*`。
- 不在 `localStorage`、`sessionStorage` 保存管理员 Token、API Key 明文或厂商密钥。
- 动态文本使用 `textContent` 渲染，禁止直接拼接不可信 `innerHTML`。

## 开发任务

- [x] 创建 `public/admin/index.html`、`assets/js`、`assets/css` 目录。
- [x] 实现 `api.js`，统一封装请求、CSRF、401、403、错误码和 `request_id`。
- [x] 实现登录页、退出、当前用户、权限菜单。
- [x] 实现基础布局：侧边菜单、顶部状态、内容区域、表格、筛选器、弹窗。
- [x] 实现用户管理页面。
- [x] 实现部门树页面，支持新增、移动、排序、停用。
- [x] 实现厂商、模型、价格配置页面。
- [x] 实现 API Key 管理页面，Key 明文只展示一次。
- [x] 实现用量明细页面，支持筛选、查看内容、导出。
- [x] 实现多模态任务和媒体资产页面。
- [x] 实现日志中心、导出任务、审计日志页面。
- [x] 实现系统设置页面：内容留存、日志留存、安全设置。

- [x] 实现安全和性能看板：WAF 命中、IP 拦截、脱敏事件、队列堆积、P95/P99。

## 测试任务

- [x] 未登录访问 Admin 自动进入登录页。
- [x] 401、403 错误能统一提示并处理。
- [x] 普通用户看不到管理菜单，直接请求接口也被服务端拒绝。
- [x] Admin JS 控制台不打印敏感响应。
- [x] CSP 生效后外部脚本和内联脚本被阻止。
- [x] 大屏查询接口响应小于 1 秒。
- [x] 管理员看不到非授权部门排行。
- [x] 排行榜能按调用次数、Token、模态次数、异常数排序。
- [x] 成本未配置时成本组件隐藏或置灰。

## 验收标准

- Admin 后台可完成系统日常配置和查询。
- 智慧大屏支持运营、安全、性能、成本和多模态分析。
- 前端权限隐藏不替代服务端权限校验。
- 前端不保存敏感凭证。
