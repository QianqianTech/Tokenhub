# 高级设置字段中文化设计

## 目标

将管理端“高级设置”中内置配置的字段摘要和编辑表单尽量显示为中文，同时保持配置键、字段路径、保存 JSON、接口和既有数据完全不变。

## 范围

- 修改 `public/admin/assets/js/table.js` 的内置配置字段展示映射。
- 修改 `tests/Frontend/AdminSettingsCenterFrontendTest.php`，以契约测试锁定中文字段映射和回退规则。
- 不修改 `/admin-api/system-settings` 的任何接口、PHP 服务、数据库或迁移。

## 方案

在 `SYSTEM_SETTING_FIELD_LABELS` 中按“系统配置键 + 字段路径”定义中文标签。卡片摘要和编辑表单通过同一解析函数读取这份映射；数组字段保留“每行一项”的输入提示。未登记的自定义配置仍显示原始路径，避免猜测并改变管理员自定义配置的语义。

## 验收标准

1. 内容留存策略中 `users / <ID> / days` 等已知字段显示中文标签。
2. 摘要卡片与编辑弹窗使用一致的中文标签。
3. 未登记的自定义字段保持原始路径，保存值和请求载荷不变。
4. 前端契约测试及 JavaScript 语法检查通过。
