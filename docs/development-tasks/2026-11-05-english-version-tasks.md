## 交付方式

建议同一套部署支持 `zh-CN` 和 `en-US`，默认简体中文。首次使用可在登录前选择 `简体中文 / English`，登录后也能切换。Web 和原生入口按当前浏览器或设备记住选择，并按部署站点隔离。英文版以英文显示平台自有界面和通知，原样展示业务数据、模型名称、知识库内容和上游原文。对外 API、历史数据、鉴权和导出格式维持兼容。

- **P0 后台英文预览**。完成语言机制、后台全部可访问页面和双语回归测试。
- **P1 完整英文发布**。在 P0 基础上覆盖移动端、大屏、通知、原生安装包、部署脚本和英文文档，通过安装与升级验收。
- **P2 按需增强**。部署级默认语言、账号级跨设备同步等选项另行排期。
