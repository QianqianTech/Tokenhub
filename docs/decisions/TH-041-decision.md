# TH-041 决策记录：多租户与企业身份集成

状态：**待决策**（2026-10-28 起草）

## 问题

是否需要多企业隔离，以及 SSO / MFA？

## 选项

多租户、SSO、MFA 分别决策：
- 多租户：所有表增加 tenant_id 并在缓存、队列、文件、RAG、统计与管理员访问上隔离，迁移成本高。
- SSO：OIDC/SAML 登录管理后台，身份生命周期与部门同步对齐。
- MFA：管理员 TOTP。

## 建议

内部单企业部署：不做多租户；管理员 MFA 优先，SSO 视现有身份系统决定。

## 若实施的验收要求

若实施多租户，回归需覆盖缓存键（ConfigVersion 之外需加租户维度）、队列、文件、RAG、统计与管理员访问。
