# TH-040 决策记录：普通用户自助台

状态：**待决策**（2026-10-28 起草）

## 问题

API 使用者是否需要自行申请 Key、查看额度和调用记录？

## 选项

A. 维持 API-only：用户通过管理员获得 Key，额度与记录通过 /v1/quota、/v1/usage/* 自查。
B. 最小自助台：只读查看自己的 Key（掩码）、额度与最近调用，Key 申请走审批。
C. 完整工作台：在线聊天、Key 自助创建、团队管理。

## 建议

先采用 A，若需求明确再做 B；C 与当前内部治理定位不符。

## 若实施的验收要求

若选 B：普通用户只能访问自己的数据；申请、审批、撤销均审计；复用 AssetAccessPolicy 与额度视图。
